
# 🧠 Clustering Penggunaan AI pada Mahasiswa

Program Python yang dibuat sebagai bagian dari tugas besar kelompok mata kuliah Matematika.

## 📌 Deskripsi Proyek
Program ini menerapkan algoritma K-Means Clustering untuk mengelompokkan mahasiswa berdasarkan pola penggunaan AI dalam kegiatan perkuliahan.

## ✨ Fitur Program
- Mengolah 34 data kuesioner mahasiswa
- Mengonversi data kuesioner menjadi data numerik
- Menghitung jarak menggunakan Euclidean Distance
- Melakukan proses K-Means Clustering
- Mengelompokkan mahasiswa menjadi 3 cluster
- Menampilkan proses iterasi dan hasil pengelompokan

## 💻 Teknologi
- Python
- Algoritma K-Means Clustering
- Modul math

## 🚀 Cara Menjalankan
1. Download file Python dari repository.
2. Pastikan Python sudah terinstal.
3. Buka terminal di folder tempat file disimpan.
4. Jalankan perintah berikut:

   ```bash
   python clustering_penggunaan_ai_mahasiswa_anonim.py
   ```

5. Ikuti instruksi yang muncul di terminal.
